# Установка и запуск

## Требования

Для готового JAR нужна Java 17 или новее с модулем java.desktop. Для компиляции — JDK 17+. Проверьте `java -version`; для сборки также `javac -version`. Рабочее окно требует графической среды. Экспорт PNG работает без дисплея.

## Windows

Распакуйте ZIP полностью. Откройте `run.bat` или выполните в папке проекта:

```bat
java -jar abandoned-rose-symbolism.jar
```

## macOS и Linux

```sh
sh run.sh
```

macOS должен иметь установленную Java, а Linux — доступный графический сеанс для окна.

## Экспорт

```sh
java -Djava.awt.headless=true -jar abandoned-rose-symbolism.jar --export rose.png
```

Получается PNG 1600 × 1600. Существующий файл по этому пути заменяется. Родительская папка должна существовать. Путь с пробелами заключайте в кавычки. Скрипты запуска переходят в папку проекта, поэтому относительные пути при запуске через них отсчитываются от неё.

## Просмотр без Java

Откройте `preview.png` либо `architekture.html`. Это сохранённое превью; после изменения кода его нужно заново экспортировать. HTML описывает архитектуру, а приложение запускается отдельно.
