# Установка и запуск

## Требования

Для готового JAR нужна Java 17 или новее с модулем java.desktop. Для компиляции — JDK 17+. Проверьте `java -version`; для сборки также `javac -version`. Рабочее окно требует графической среды. Экспорт PNG работает без дисплея.

## Windows

Распакуйте ZIP полностью. Откройте `run.bat` или выполните в папке проекта:

```bat
java -jar abandoned-rose-symbolism.jar
```

## macOS и Linux

```sh
sh run.sh
```

macOS должен иметь установленную Java, а Linux — доступный графический сеанс для окна.

## Управление в окне

| Действие | Как |
|---|---|
| Повернуть розу | перетащить мышью; ← → (по 12°), ↑ ↓ (наклон по 5°) — клик по картинке даёт фокус |
| Исходный ракурс | двойной щелчок или Home |
| Медленное вращение | флажок **Turntable** |
| Сохранить текущий вид | **Save PNG…** (1600 × 1600, в фоне) |
| Новая вариация / назад / вперёд | REDRAW / BACK / FORWARD |
| Форма цветка | Bloom, Petal layers, Morning dew |

## Экспорт

```sh
java -Djava.awt.headless=true -jar abandoned-rose-symbolism.jar --export rose.png
```

Получается PNG 1600 × 1600 (или `--size N`). Остальные флаги — `--style`, `--hue`, `--seed`, `--yaw`, `--pitch`, `--bloom`, `--layers`, `--dew` — описаны в README. Существующий файл по этому пути заменяется. Родительская папка должна существовать. Путь с пробелами заключайте в кавычки. Скрипты запуска переходят в папку проекта, поэтому относительные пути при запуске через них отсчитываются от неё.

## Просмотр без Java

Откройте `preview.png` либо `architekture.html`. Это сохранённое превью; после изменения кода его нужно заново экспортировать. HTML описывает архитектуру, а приложение запускается отдельно.
