# Архитектура

## Компоненты

| Компонент | Ответственность |
|---|---|
| `RoseDrawing` | JPanel, точка входа, рендер и экспорт |
| `RoseDrawing_2` | Устаревшее имя запуска, делегирует основной точке входа |
| `RoseRenderingCheck` | Автономные проверки без JUnit/Mockito |
| `architekture.html` | Локальная документация с изображением |

## Поток выполнения

`main` разбирает аргументы. При `--export PATH` вызывает `renderScene(1600,1600)` и ImageIO.write. Без аргументов проверяет наличие дисплея и создаёт JFrame через SwingUtilities.invokeLater.

Swing вызывает `paintComponent`. Панель использует кэш BufferedImage. При первом показе и изменении ширины/высоты создаётся новый буфер; повторная перерисовка в том же размере использует старый. Метод redraw меняет Appearance и сбрасывает кэш; resize сохраняет Appearance.

`renderScene` создаёт RGB-буфер, включает сглаживание, заполняет фон полей и переносит квадратный логический холст в центр. `paintArtwork` выполняет последовательное рисование слоёв. Вспомогательные методы `petal`, `leaf`, `fallen` работают с отдельными копиями Graphics2D; `path` строит кубические кривые Безье.

## Координаты

Логический холст — 1000 × 1000. Масштаб `min(width,height)/1000`. Смещения `(width-1000*scale)/2` и `(height-1000*scale)/2` сохраняют пропорции. Свободные области заполняются тёмным цветом.

## Ресурсы и потоки

Graphics2D освобождается через dispose. BufferedImage управляется сборщиком мусора. Публичный renderScene создаёт локальные объекты и не использует кэш панели. Swing-панель должна изменяться в EDT. Первый рендер и изменение размера выполняются в EDT; на очень больших размерах возможна задержка. Фоновые задачи и анимация не реализованы. Кнопка REDRAW работает в EDT и обновляет палитру, тон и стиль.

## Внешние зависимости

Runtime использует только Java SE. Maven — альтернативный инструмент сборки и требует загрузки плагинов при первом запуске. Скрипты JDK собирают без сети. Базы данных, HTTP, телеметрия и настройки пользователя отсутствуют.
