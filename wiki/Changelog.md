# Изменения 2.0.0

## Исправлено

Исходный RoseDrawing_2 объявлял `public void RoseDrawing()` как обычный метод и присваивал final-полю image новое значение, что приводило к ошибке компиляции. Дублирование отрисовки устранено: старое имя запуска делегирует RoseDrawing.

## Изменено

Четыре красных круга и геометрический разноцветный фон заменены многослойной розой с градиентами, листвой, шипами, опавшими лепестками, аркой и фактурой. Минимальная версия сборки снижена с Java 21 до Java 17. Mockito/JUnit и избыточный shade-plugin убраны; runtime-зависимостей нет.

## Добавлено

CLI-экспорт PNG, готовый JAR, скрипты сборки/запуска/проверки, регрессионная проверка реального рендера, PNG-превью, architekture.html и Wiki.

## Ограничения

Рисунок статичен: нет анимации последовательного рисования, редактора, кнопки экспорта в GUI или интерактивной палитры. Экспорт вызывается командой. Это программная векторная стилизация. Шрифты системные. Очень большой буфер может вызвать нехватку памяти. Будущие возможные улучшения: конфигурация палитры, анимация раскрытия, отдельный renderer-класс, фоновый рендер; они не входят в текущую версию.
