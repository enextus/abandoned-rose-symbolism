# Изменения 2.1.0

## Исправлено

Исходный RoseDrawing_2 объявлял `public void RoseDrawing()` как обычный метод и присваивал final-полю image новое значение, что приводило к ошибке компиляции. Дублирование отрисовки устранено: старое имя запуска делегирует RoseDrawing.

## Изменено

Четыре красных круга и геометрический разноцветный фон заменены многослойной розой с градиентами, листвой, шипами, опавшими лепестками, аркой и фактурой. Минимальная версия сборки снижена с Java 21 до Java 17. Mockito и избыточный shade-plugin убраны; JUnit Jupiter 6.1.3 подключён для Maven-тестов; runtime-зависимостей нет.

## Добавлено

CLI-экспорт PNG, готовый JAR, скрипты сборки/запуска/проверки, регрессионная проверка реального рендера, PNG-превью, architekture.html и Wiki.

## Ограничения

Рисунок статичен между нажатиями REDRAW. Нет анимации, редактора и кнопки экспорта в GUI; REDRAW выбирает случайную палитру и стиль. Экспорт вызывается командой. Это программная векторная стилизация. Шрифты системные. Очень большой буфер может вызвать нехватку памяти. Будущие возможные улучшения: ручная конфигурация палитры, анимация раскрытия, отдельный renderer-класс, фоновый рендер; они не входят в текущую версию.
