# Устранение проблем

| Симптом | Причина и действие |
|---|---|
| java не найден | Установите Java 17+ и добавьте bin в PATH, затем откройте новый терминал |
| javac не найден | Для сборки нужен JDK; готовый JAR можно запускать без компилятора |
| UnsupportedClassVersionError | Используется Java старее 17; проверьте java -version и PATH |
| No display | Нет графической среды; используйте --export rose.png |
| Unable to access jarfile | Перейдите в распакованную папку, не запускайте из просмотра ZIP |
| Ошибка записи PNG | Проверьте существование папки и права записи |
| Maven не скачивает плагины | Используйте JDK-скрипты без сети либо настройте Maven repository/proxy |
| После Maven виден старый рисунок | Запускайте JAR из target, либо пересоберите корневой JAR через build |
| HTML без картинки | Сохраните preview.png рядом с architekture.html |
| Wiki отображается текстом | Откройте Markdown-редактором; HTML-обзор читается в обычном браузере |
| При растягивании картинка на миг мягче | Это прежний кадр, масштабированный, пока в фоне считается новый; через долю секунды он заменится |
| Вращение рывками на слабом ПК | Предпросмотр считает 1 сэмпл/пиксель; уменьшите окно — время кадра пропорционально площади |
| Первый кадр после запуска ~1 с | Строится 3D-модель и затенение неба (кэшируются); дальнейшие кадры быстрее |
| Стрелки не вращают розу | Щёлкните по картинке, чтобы она получила фокус клавиатуры |

Не запускайте build.bat двойным щелчком для диагностики: откройте терминал в папке, чтобы увидеть полный текст ошибки. Используйте кавычки для путей с пробелами.
